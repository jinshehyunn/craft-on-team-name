## 게임 소개

- **장르**: 2D 탑다운 액션
- **재미 포인트**:
  - 점점 빨라지는 적 웨이브
  - 아이템 조합으로 만드는 나만의 빌드

## 조작법

| 키 | 동작 |
|----|------|
| `W` `A` `S` `D` | 이동 |
| `마우스 좌클릭` | 공격 |
| `Space` | 대시 |
| `ESC` | 일시정지 |
